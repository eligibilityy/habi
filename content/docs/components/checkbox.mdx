## When to use

Use checkboxes when people can tick more than one answer, or none:

- **One checkbox** for a yes or no answer, like confirming their details are correct.
- **A group of checkboxes** when people can pick several options, like which IDs they can bring.

Use something else when:

- **Only one answer is allowed.** Use a [Radio group](/docs/components/radio-group), which makes that clear: picking one option clears the others.
- **It filters what's on the page** straight away, outside a form. Use [Tags](/docs/components/tag).

## Usage

```tsx
import { Checkbox } from "@/components/ui/checkbox";
import { ChoiceLabel, Field } from "@/components/ui/field";

<Field>
  <ChoiceLabel>
    <Checkbox name="hasPhilId" />
    I have a PhilID
  </ChoiceLabel>
</Field>;
```

`ChoiceLabel` wraps the checkbox and its text, so the whole 48px row can be pressed.

## Content guidelines

- **The legend asks the question:** "Which IDs can you bring?"
- **Add "Select all that apply"** as a description under the legend, so people know they can tick more than one.
- **Write a single checkbox as a statement people agree with:** "The details I gave are true and correct".
- **Start each option with a capital letter** and leave off the full stop, so the list is easy to scan.

## Accessibility

### What Habi handles

- **Whole row:** `ChoiceLabel` wraps the box and the text, so the full 48px row can be pressed, not just the 20px box.
- **Group question:** the legend names the group, so screen readers read the question with the options.
- **Keyboard:** <kbd>Tab</kbd> moves between checkboxes and <kbd>Space</kbd> ticks or clears one.
- **State:** screen readers announce "checked", "not checked" or "mixed". The box shows a check or a dash, not just a color.

### What you need to do

- **Ask the question in a `FieldsetLegend`** for every group, so screen reader users hear it with the options.
- **Use Base UI's `Form`**, or your own submit handling, to move focus to the first problem after people submit. Errors appear below the group or checkbox.
