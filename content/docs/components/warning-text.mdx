## When to use

Use warning text when not doing something could cost people: a fine, a cancelled application or a missed deadline. Put it next to the thing it's about.

Use it once per page at most. Use [Inset text](/docs/components/inset-text) for something people should notice but that won't cost them, and a [Notification](/docs/components/notification) for messages about the whole page.

## Usage

```tsx
import { WarningText } from "@/components/ui/warning-text";

<WarningText>
  Your appointment will be cancelled if you don’t pay within 3 days.
</WarningText>;
```

## Content guidelines

- **Say what will happen and when:** "Your appointment will be cancelled if you don't pay within 3 days", not "Pay on time".
- **Keep it to one sentence.**

## Accessibility

### What Habi handles

- **"Warning" is read out first,** as hidden text, and the "!" circle is hidden from screen readers. The warning doesn't rely on the icon.
- **The text is bold** (`<strong>`), as well as next to the icon.

### What you need to do

- **Translate `label`** when the page isn't in English.
