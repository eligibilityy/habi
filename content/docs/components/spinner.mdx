## When to use

Use a spinner when people have to wait for something they asked for, like a payment being checked or a search running. It tells them the service hasn't stopped.

Use something else when:

- **You know how far along it is,** like an upload. Show the progress, as [File input](/docs/components/file-input) does.
- **It's quick.** Don't show a spinner for less than a second: it flashes and distracts.

## Usage

```tsx
import { Spinner } from "@/components/ui/spinner";

<Spinner size="medium" label="Checking your payment…" />;
```

Always set `label` to say what's loading. It's hidden next to the ring, but screen readers read it out. It turns once a second.

## Examples

### With a label

Show the label with `showLabel` when people would otherwise wonder what they're waiting for.

### In a button

Inside a Primary [Button](/docs/components/button), use a Small Inverse spinner in place of the icon, and change the button's words to say what's happening. Ignore more presses until it's done, so people aren't charged twice.

## Accessibility

### What Habi handles

- **A status message,** with `role="status"`, so screen readers read the label without moving focus.
- **Reduced motion:** with reduced motion turned on, the ring stops turning and the label shows instead.

### What you need to do

- **Set a `label` that says what's loading.** "Loading…" alone doesn't tell people much.
- **Add the spinner to a part of the page that's already there,** or announce the wait another way. Some screen readers only read a status message when it changes, not when it first appears.
- **Move focus or announce the result** when loading finishes, so screen reader users know it's done.
