## When to use

Use an accordion when people only need some of the sections on a page, and can tell from the headings which ones:

- **Frequently asked questions:** "What documents do I need?", "How long does it take?"
- **Requirements that depend on the person:** a section for first-time applicants and one for renewals.

Use something else when:

- **Everyone needs the content,** like fees and deadlines. Show it on the page. People miss what's hidden.
- **There's only one section.** Show the content.
- **The sections are steps people go through in order.** Ask one thing per page instead.

## Installation

[Set up Habi](/docs/installation) first, if you haven't already. Then add the component with the shadcn CLI, which also adds the Habi parts it uses:

```npm
npx shadcn@latest add https://habi.yiliya.studio/r/accordion.json
```

To add it by hand instead, install the packages this component uses:

```npm
npm install @base-ui/react @heroicons/react
```

## Usage

```tsx
import {
  Accordion,
  AccordionItem,
  AccordionPanel,
  AccordionTrigger,
} from "@/components/ui/accordion";

<Accordion>
  <AccordionItem>
    <AccordionTrigger>What documents do I need?</AccordionTrigger>
    <AccordionPanel>
      One valid government ID and your PSA birth certificate.
    </AccordionPanel>
  </AccordionItem>
</Accordion>;
```

Each `AccordionItem` has a border above it, and `Accordion` adds one below the last item.

## Examples

### Several open at once

By default, opening an item closes the one that was open. Add `multiple` when people may need to compare sections, like requirements that apply to them. Give items a `value` and list the ones to open first in `defaultValue`.

## Content guidelines

- **Write headings people can scan:** a question they'd ask ("Can someone else pick it up?") or a short label ("If you're renewing your passport").
- **Answer in the first sentence** of each panel, then add the details.
- **Keep panels short.** Text, a short list or a link to a full page.
- **Don't hide what everyone needs,** like fees, deadlines or the main requirements.

## Accessibility

### What Habi handles

- **One button per heading:** the whole heading row is a button inside a heading, so people can open an item with a click, a tap, <kbd>Enter</kbd> or <kbd>Space</kbd>.
- **Open or closed is read out:** the button has `aria-expanded`, and its panel is labelled by the heading. The chevron is hidden from screen readers.
- **Keyboard:** <kbd>Tab</kbd> moves from one heading to the next, and into an open panel's links.
- **Find in page:** closed panels stay on the page, so the browser's find in page (<kbd>Ctrl</kbd> + <kbd>F</kbd>) can find text in them and opens the item. Older browsers skip closed panels.
- **Reduced motion:** items open and close without animating when people ask their device for less motion.

### What you need to do

- **Set `level`** so the headings fit the page. Under an `h2`, the default `h3` is right.
- **Don't put interactive content in `AccordionTrigger`.** It's already a button.
