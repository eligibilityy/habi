## When to use

Put a skip link first on every page. People who use a keyboard or a screen reader would otherwise Tab through the banner, the header and the menu on every page before reaching the content.

It's hidden until someone presses <kbd>Tab</kbd>. Then it shows at the top left of the page, above everything else.

## Usage

```tsx
import { SkipLink } from "@/components/ui/skip-link";

<body>
  <SkipLink />
  <OfficialBanner />
  <header>…</header>
  <main id="main-content">…</main>
</body>;
```

Make it the first thing in `<body>`, and give your `<main>` the `id` it links to, `main-content` by default. Selecting it moves focus to the main content, so the next <kbd>Tab</kbd> goes to the first link or field there.

## Accessibility

### What Habi handles

- **Hidden until focused,** but never removed from the page, so <kbd>Tab</kbd> and screen readers still reach it.
- **Moves focus** to the main content, not just the scroll position. It gives the target `tabindex="-1"` until focus leaves, as `<main>` can't take focus otherwise.
- **A focus border and shadow,** so it stands out over whatever is at the top of the page.

### What you need to do

- **Make it the first focusable thing** on the page.
- **Give `<main>` the matching `id`.** Without it, the link does nothing.
