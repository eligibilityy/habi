## When to use

Use a phase banner while a service is being tested, so people know to expect changes and can tell you what's not working. Put it directly under the header, on every page of the service.

Remove it when the service is live.

## Installation

[Set up Habi](/docs/installation) first, if you haven't already.

Phase banners link to a feedback form, so add [Link](/docs/components/link) too.

## Usage

```tsx
import { Link } from "@/components/ui/link";
import { PhaseBanner } from "@/components/ui/phase-banner";

<PhaseBanner phase="Beta">
  This is a new service. Your feedback will help us improve it.
  <Link href="/feedback" size="small">
    Give feedback
  </Link>
</PhaseBanner>;
```

On computers the link follows the message. Below 640px wide, it goes on its own line.

## Content guidelines

- **"Alpha"** means a small group is testing the service. **"Beta"** means anyone can use it, but it's still improving.
- **Keep the message to one sentence,** and link to a short feedback form.

## Accessibility

### What Habi handles

- **The phase is a word, not a color,** so it's read out with the message: "Beta. This is a new service…".

### What you need to do

- **Say where the link goes,** like "Give feedback", not "Click here".
