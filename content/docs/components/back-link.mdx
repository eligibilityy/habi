## When to use

Use a back link at the top of each page of a multi-page form, so people can change an earlier answer. Put it above the step indicator and heading, outside the `<form>`.

Leave it out on the first page of a service. Use a [Breadcrumb](/docs/components/breadcrumb) to go back up a site's sections instead.

## Usage

```tsx
import { BackLink } from "@/components/ui/back-link";

<BackLink href="/apply/address" />;
```

Link to the previous step's URL, not to the browser's history. The link works before JavaScript loads, and people come back to their saved answers, not a resubmitted form.

`BackLink` is a [Link](/docs/components/link), so to use your framework's link, like Next.js's, pass it with `render`.

## Accessibility

### What Habi handles

- **A real link,** so it works with a keyboard, before JavaScript loads, and in a screen reader's links list.
- **The chevron is hidden** from screen readers, so they read "Back, link".
- **Keyboard:** <kbd>Tab</kbd> reaches it, with a focus ring around the chevron and the words.

### What you need to do

- **Link to the previous step,** and keep people's answers when they go back.
