## When to use

Use a tooltip to:

- **Name an icon-only button**, like "Copy reference number".
- **Give a brief hint** about a control.

Don't use a tooltip for anything people need. Phones have no hover, so most people on phones never see it. Never put essential information, links or actions in one: write them on the page.

## Usage

```tsx
import { Button } from "@/components/ui/button";
import {
  Tooltip,
  TooltipContent,
  TooltipTrigger,
} from "@/components/ui/tooltip";

<Tooltip>
  <TooltipTrigger
    render={<Button iconOnly aria-label="Copy reference number" />}
  >
    <ClipboardDocumentIcon />
  </TooltipTrigger>
  <TooltipContent>Copy reference number</TooltipContent>
</Tooltip>;
```

The tooltip opens after a short delay, on the top side by default. Near the edge of the screen, it moves to stay in view.

## Content guidelines

- **Use the same words as the control's `aria-label`**, like "Download receipt".
- **Keep it to one short line.** Longer text wraps at 240px.
- **Name the action, don't explain it:** "Print receipt", not "Click here to print your receipt".

### Tooltip and TooltipProvider

`Tooltip` groups a trigger and its tooltip. `TooltipProvider` shares timing across several tooltips. They also accept the props of Base UI's [Tooltip Root](https://base-ui.com/react/components/tooltip#root) and [Provider](https://base-ui.com/react/components/tooltip#provider), like `delay`.

## Accessibility

### What Habi handles

- **It opens on hover and on keyboard focus,** after a short delay.
- **It stays open while the pointer is over it,** and <kbd>Esc</kbd> closes it without moving focus (WCAG 1.4.13).
- **Contrast:** light text on a dark background, with an arrow that points at the control.

### What you need to do

- **Name the control itself.** Screen readers and touch screens don't use the tooltip, so give an icon-only button an `aria-label` with the same words.
- **Don't put anything people need in a tooltip.** Write it on the page.
