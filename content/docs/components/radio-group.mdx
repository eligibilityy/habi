## When to use

- **5 or fewer options** that people should compare, like how to get a document or how to pay.
- **6 or more options:** use a Select.
- **Several answers allowed:** use checkboxes.

## Usage

```tsx
import {
  ChoiceLabel,
  Field,
  FieldItem,
  Fieldset,
  FieldsetLegend,
} from "@/components/ui/field";
import { Radio, RadioGroup } from "@/components/ui/radio";

<Field name="collection">
  <Fieldset render={<RadioGroup />}>
    <FieldsetLegend>How do you want to get your clearance?</FieldsetLegend>
    <FieldItem>
      <ChoiceLabel>
        <Radio value="pickup" />
        Pick up in person
      </ChoiceLabel>
    </FieldItem>
  </Fieldset>
</Field>;
```

## Accessibility

- **Whole row:** the label wraps the radio and its text, so the full 48px row can be pressed.
- **Group question:** the legend names the group, so screen readers read the question with the options.
- **Keyboard:** <kbd>Tab</kbd> moves into the group, landing on the selected option. The arrow keys move between options and select them. <kbd>Tab</kbd> again leaves the group.
- **State:** the selected option has a filled dot, not just a color change.
- **Order:** stack options vertically, so they're easy to scan and compare.
