## When to use

Use a breadcrumb on sites with more than two levels, like Home / Services / Passport, so people can see where they are and go back up. Put it above the page title.

Use something else when:

- **The site is flat**, with every page one level below the home page.
- **People are going through the steps of a form.** Show their progress in the form, not the site's structure.

## Usage

```tsx
import {
  Breadcrumb,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbList,
  BreadcrumbPage,
  BreadcrumbSeparator,
} from "@/components/ui/breadcrumb";

<Breadcrumb>
  <BreadcrumbList>
    <BreadcrumbItem>
      <BreadcrumbLink href="/">Home</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbLink href="/services">Services</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbPage>Passport</BreadcrumbPage>
    </BreadcrumbItem>
  </BreadcrumbList>
</Breadcrumb>;
```

End with the current page as a `BreadcrumbPage`, not a link. On phones, the breadcrumb shows only the page above it, as a back link: "‹ Services". To use your framework's link, like Next.js's, pass it to `BreadcrumbLink` with `render`, the same way as [Link](/docs/components/link).

## Content guidelines

- **Use each page's title,** or a shorter form of it people will recognize: "Passport", not "Passport application and renewal services".
- **Start from the home page** of the site or service.

## Props

`Breadcrumb` is a `<nav>`, `BreadcrumbList` an `<ol>`, `BreadcrumbItem` and `BreadcrumbSeparator` are `<li>`s, and `BreadcrumbPage` and `BreadcrumbEllipsis` are `<span>`s. Each accepts its element's props.

## Accessibility

### What Habi handles

- **A navigation landmark** named "Breadcrumb", so screen reader users can find it and know what it is.
- **An ordered list,** so screen readers say how many levels there are.
- **The current page** has `aria-current="page"`, so screen readers say it's the current page.
- **Separators and "…" are hidden** from screen readers.
- **Keyboard:** <kbd>Tab</kbd> moves through the links in order, with a focus ring on each.

### What you need to do

- **Make the last item the current page** with `BreadcrumbPage`, so it isn't a link to the page people are on.
- **Translate `aria-label`** when the page isn't in English.
