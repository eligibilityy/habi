title: Color

Habi has two layers of color tokens:

- **Semantic tokens** say what a color is for, like `link/primary` or `button/danger`. Use these in designs and code.
- **Primitives** are the raw palette, like `blue/70`. Semantic tokens point at them. Don't use primitives directly.

In code, every token is a CSS variable (`--link-primary`) and a Tailwind color you can use with any color utility: `text-link-primary`, `bg-button-primary`, `border-border-subtle-01`.

Every text, link and icon color passes WCAG 2.2 AA on every background, layer and field color: at least 4.5:1 for text and 3:1 for icons. Disabled text is lighter, which WCAG allows for controls people can't use. If you combine tokens in a new way, check the contrast first.
