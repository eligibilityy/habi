Habi uses **Allo**, a rounded variable typeface by Josh Puckett, released under the SIL Open Font License. Allo has a roundness axis, and Habi sets it to 100, the roundest setting.

## Text styles

Use a text style rather than setting size, line height and weight separately. Each style is a single Tailwind class.

## Weights

| Weight   | Value | Tailwind        |
| -------- | ----- | --------------- |
| Regular  | 400   | `font-regular`  |
| Medium   | 500   | `font-medium`   |
| Semibold | 600   | `font-semibold` |
| Bold     | 700   | `font-bold`     |

## Numbers and reference codes

Use the monospace font (`font-mono`) for reference and ID numbers, grouped so they're easy to read aloud: `NBI-2026-1215-0417`.
