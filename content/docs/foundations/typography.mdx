Habi uses **Allo**, a rounded variable typeface by Josh Puckett, released under the SIL Open Font License. Allo has a roundness axis, and Habi sets it to 100, the roundest setting.

## Text styles

Use a text style rather than setting size, line height and weight separately. Each style is a single Tailwind class.

## Weights

| Weight   | Value | Tailwind        |
| -------- | ----- | --------------- |
| Regular  | 400   | `font-regular`  |
| Medium   | 500   | `font-medium`   |
| Semibold | 600   | `font-semibold` |
| Bold     | 700   | `font-bold`     |

## Numbers and reference codes

Use the monospace font (`font-mono`) for reference and ID numbers, grouped so they're easy to read aloud: `NBI-2026-1215-0417`.

## Readability

- **Body text is `text-body-md` (16px).** Use the smaller styles, which are 14px, only for labels, hints and secondary details.
- **Inputs use 16px text,** so phones don't zoom in when people tap a field.
- **Sizes are in `rem`,** so text grows when people raise their browser's text size or zoom in (WCAG 1.4.4).
- **Keep long text to 680px wide at most,** about 70–80 characters a line. Longer lines are harder to follow from one line to the next.

## Loading the font

Allo is one 448 KB variable file. It loads with `font-display: swap`, so text appears straight away in the system font and switches to Allo when the file arrives. People on slow connections can start reading immediately.
