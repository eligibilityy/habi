Habi's spacing tokens match Tailwind's default spacing scale, where each step is 4px. In code, use Tailwind's spacing classes (`p-4`, `gap-6`, `mt-8`) directly. The table shows which Figma token each one matches.

<SpacingScale />

The same numbers work with every spacing utility: padding (`p-`), margin (`m-`), gap (`gap-`), width (`w-`) and height (`h-`).
