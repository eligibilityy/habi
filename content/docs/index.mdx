More and more people use government services online: booking an NBI clearance, applying for a passport, getting a TIN. Those services should be easy to use, accessible to everyone and consistent from one agency to the next.

**Habi** is a design system for building them. It gives designers a Figma library and developers matching React components, built on the same design tokens, with guidance on when and how to use each one. Habi is Filipino for _weave_: design, code and guidance woven from the same threads.

## What is Habi?

- **Foundations:** color, type, spacing, radius, elevation and motion, the decisions every component is built on.
- **Components:** ready-made parts like buttons, form fields, search and file upload, each with guidance, React code and accessibility notes.
- **Figma library:** every component with its variants and states, plus designs for whole service patterns like booking an appointment.
- **Content guidance:** how to word labels, hints and errors in plain language.

## Why use Habi?

- **Easy-to-use services:** calm, uncluttered pages, one task at a time, in plain words.
- **Faster to build:** teams copy ready-made components and spend their time on the service, not the buttons.
- **Consistent across agencies:** the same look and behaviour everywhere, so people know what to expect.
- **Accessible from the start:** components aim for WCAG 2.2 AA, so services work with a keyboard, a screen reader or zoomed-in text.
- **Made for phones:** everything is designed for a 375px screen first, where most people use government services.

## Use cases

- **Online services:** applications, renewals, bookings and payments, like an NBI clearance or a passport appointment.
- **Agency websites:** pages that explain a service, what it needs and how much it costs.

## Principles

- **Plain language.** Write in plain English, with a Filipino option.
- **Mobile first.** Design for a 375px phone screen first. Many people use government services on a phone.
- **Accessible.** Aim for WCAG 2.2 AA, so people can use every service with a keyboard, a screen reader or zoomed-in text.
- **Calm and friendly.** Neutral colors, rounded type and soft corners.
- **One task per screen.** Ask for one thing at a time.
- **No surprises.** Show fees and waiting times up front.
