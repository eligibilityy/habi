**Habi** is a design system for digital government services in the Philippines:
things like booking an NBI clearance, applying for a passport or getting a TIN.
It gives designers a Figma library and developers matching React components, 
built on the same design tokens.

## Principles

- **Plain language.** Write in plain English, with a Filipino option.
- **Mobile first.** Design for a 375px phone screen first.
- **Accessible.** Meet WCAG 2.2 AA.
- **Calm and friendly.** Neutral colors, rounded type and small corner radii.
- **One task per screen.** Ask for one thing at a time.
- **No surprises.** Show fees and waiting times up front.
