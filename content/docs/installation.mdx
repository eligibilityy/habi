Habi's components are React components styled with Tailwind CSS. You add each component's code to your project, with the shadcn CLI or by copying it, so you can read it and change it. This page sets up what every component shares: Habi's typefaces, its styles and the `cn` helper.

You need a React project with **Tailwind CSS v4**. The examples on this site use Next.js.

## 1. Add the typefaces

```npm
npm install allo-font @fontsource/jetbrains-mono
```

- **`allo-font`** is Allo, Habi's typeface.
- **`@fontsource/jetbrains-mono`** is JetBrains Mono, for reference numbers and shortcut hints.

Import both stylesheets once, in your root layout:

```tsx title="app/layout.tsx"
import "allo-font/allo.css";
import "@fontsource/jetbrains-mono/400.css";
```

## 2. Add Habi's styles

Copy both files next to your global stylesheet:

<ComponentSource src="registry/habi/styles/habi.css" title="app/habi.css" />

<ComponentSource
  src="registry/habi/styles/habi-tokens.css"
  title="app/habi-tokens.css"
/>

Then import `habi.css` right after Tailwind:

```css title="app/globals.css"
@import "tailwindcss";
@import "./habi.css";
```

This gives you:

- **Every design token** as a CSS variable and a Tailwind class, like `bg-button-primary`, `text-label`, `rounded-control` and `shadow-card`. See [Foundations](/docs/foundations/color) for the full set.
- **The `focus-ring` utility**, the 2px focus ring that buttons, links and other controls use.
- **Page defaults:** Allo at its roundest setting, with Habi's text and background colors.

`habi-tokens.css` replaces Tailwind's default color palette, so classes like `bg-blue-500` no longer exist. Use Habi's semantic colors instead, like `bg-interactive-default` or `text-text-secondary`. Their text and background pairs are checked to pass WCAG AA contrast. Don't edit this file by hand: it's generated from Habi's design tokens.

## 3. Choose how to add components

<InstallationTabs>
<InstallationTab value="command">

The shadcn CLI adds a component, the Habi parts it uses and the packages they need, in one step. It reads `components.json` to know where to put the files. Add this one at the root of your project:

```json title="components.json"
{
  "$schema": "https://ui.shadcn.com/schema.json",
  "style": "new-york",
  "rsc": true,
  "tsx": true,
  "tailwind": {
    "config": "",
    "css": "app/globals.css",
    "baseColor": "neutral",
    "cssVariables": true
  },
  "aliases": {
    "components": "@/components",
    "utils": "@/lib/utils",
    "ui": "@/components/ui",
    "lib": "@/lib",
    "hooks": "@/hooks"
  }
}
```

If your global stylesheet isn't `app/globals.css`, or your project doesn't use the `@/` alias, change `css` and `aliases` to match.

Don't create this file with `shadcn init`. It also adds shadcn's own colors to your global stylesheet, and those clash with Habi's.

Each component page has the command that adds it. For Button:

```npm
npx shadcn@latest add https://habi.yiliya.studio/r/button.json
```

The CLI also adds the `cn` helper, and changes each component's imports to match your `aliases`.

</InstallationTab>
<InstallationTab value="manual">

Components use the `cn` helper to combine their classes with yours. It knows Habi's text styles and radius roles, like `text-label` and `rounded-control`, so a class you pass replaces the component's own instead of both applying.

Install the packages it uses:

```npm
npm install clsx tailwind-merge
```

Add the helper:

<ComponentSource src="registry/habi/lib/utils.ts" title="lib/utils.ts" />

Components import each other with the `@/` alias, like `@/components/ui/field` and `@/lib/utils`. New Next.js projects set this up for you. If yours uses another alias or folder, update the imports after you copy a component.

</InstallationTab>
