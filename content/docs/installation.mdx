Habi's components are React components styled with Tailwind CSS. Each component's code goes into your project, added with the shadcn CLI or copied by hand, so you can read it and change it. This page sets up what every component shares: Habi's styles, its typeface and a small helper.

You need a React project with **Tailwind CSS v4**. The examples on this site use Next.js.

## 1. Install the shared packages

```npm
npm install allo-font @fontsource/jetbrains-mono clsx tailwind-merge
```

- **`allo-font`** is Allo, Habi's typeface.
- **`@fontsource/jetbrains-mono`** is JetBrains Mono, for reference numbers and shortcut hints.
- **`clsx`** and **`tailwind-merge`** combine class names, so a `className` you pass to a component replaces its own classes instead of clashing with them.

## 2. Load the typefaces

Import both stylesheets once, in your root layout:

```tsx title="app/layout.tsx"
import "allo-font/allo.css";
import "@fontsource/jetbrains-mono/400.css";
```

## 3. Add Habi's styles

Copy both files next to your global stylesheet:

<ComponentSource src="registry/habi/styles/habi.css" title="app/habi.css" />

<ComponentSource
  src="registry/habi/styles/habi-tokens.css"
  title="app/habi-tokens.css"
/>

Then import `habi.css` right after Tailwind:

```css title="app/globals.css"
@import "tailwindcss";
@import "./habi.css";
```

This gives you:

- **Every design token** as a CSS variable and a Tailwind class, like `bg-button-primary`, `text-label`, `rounded-control` and `shadow-card`. See [Foundations](/docs/foundations/color) for the full set.
- **The `focus-ring` utility**, the 2px focus ring that buttons, links and other controls use.
- **Page defaults:** Allo at its roundest setting, with Habi's text and background colors.

`habi-tokens.css` replaces Tailwind's default color palette, so classes like `bg-blue-500` no longer exist. Use Habi's semantic colors instead, like `bg-interactive-default` or `text-text-secondary`. Their text and background pairs are checked to pass WCAG AA contrast. Don't edit this file by hand: it's generated from Habi's design tokens.

## 4. Add the `cn` helper

Components use `cn` to combine their classes with yours. It also knows Habi's text styles and radius roles, like `text-label` and `rounded-control`, so a class you pass replaces the component's own instead of both applying.

<ComponentSource src="registry/habi/lib/utils.ts" title="lib/utils.ts" />

The shadcn CLI adds this file for you when you add your first component.

## 5. Set up the shadcn CLI

The CLI adds a component and every Habi part it uses in one step, and installs the packages they need. It reads `components.json` to know where files go. Add one at the root of your project:

```json title="components.json"
{
  "$schema": "https://ui.shadcn.com/schema.json",
  "style": "new-york",
  "rsc": true,
  "tsx": true,
  "tailwind": {
    "config": "",
    "css": "app/globals.css",
    "baseColor": "neutral",
    "cssVariables": true
  },
  "aliases": {
    "components": "@/components",
    "utils": "@/lib/utils",
    "ui": "@/components/ui",
    "lib": "@/lib",
    "hooks": "@/hooks"
  }
}
```

Don't run `shadcn init` instead. It adds shadcn's own colors to your global stylesheet, which clash with Habi's.

Then add components by their address, like Button:

```npm
npx shadcn@latest add https://habi.yiliya.studio/r/button.json
```

The CLI changes the components' imports to match your `aliases`. If you copy a component by hand instead, its imports use the `@/` alias, like `@/components/ui/field` and `@/lib/utils`. New Next.js projects set this up for you. If yours uses another alias or folder, update the imports after copying.
